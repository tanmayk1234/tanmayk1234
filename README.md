### What I'm building

**[nashik-monitor-v2](https://github.com/tanmayk1234/nashik-monitor-v2)** — Interactive map of
Nashik–Trimbakeshwar Kumbh Mela 2027 infrastructure: ghats, CCTV, parking, ring road, hospitals and
20 more layers. 7,806 features, and the 581 that are only neighbourhood-level guesses say so.
Vite + TypeScript + MapLibre GL, no framework, no backend.

**[resume-screening-system](https://github.com/tanmayk1234/resume-screening-system)** — AI-powered
resume screening with candidate and recruiter dashboards. Flask, scikit-learn, NLTK, PostgreSQL, Redis.

**[Kumbhathon-Intern-Attendance-App](https://github.com/tanmayk1234/Kumbhathon-Intern-Attendance-App)**
— Attendance app for Kumbhathon interns. Next.js + TypeScript.

**[Admin-Dashboard-Kumbhathon](https://github.com/tanmayk1234/Admin-Dashboard-Kumbhathon)** — The
admin side of that system. Next.js + TypeScript.
