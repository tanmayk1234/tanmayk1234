# Tanmay Kangane

Web developer in Nashik, Maharashtra. I build maps, dashboards and internal tools —
mostly TypeScript and Python.

Currently working on **Nashik Monitor**, a city infrastructure map for Kumbh Mela 2027,
an initiative by Kumbhathon Innovation Foundation.

### Selected work

| Project | What it is | Built with |
| --- | --- | --- |
| **[nashik-monitor-v2](https://github.com/tanmayk1234/nashik-monitor-v2)** | Kumbh Mela 2027 infrastructure map for Nashik–Trimbakeshwar: ghats, CCTV, parking, ring road, hospitals and 20 more layers, 7,806 features. The 581 features placed by locality match are labelled as such. | TypeScript, MapLibre GL, Vite |
| **[resume-screening-system](https://github.com/tanmayk1234/resume-screening-system)** | Resume screening with separate candidate and recruiter dashboards, PDF and DOCX parsing. | Flask, scikit-learn, NLTK, PostgreSQL, Redis |
| **[Kumbhathon-Intern-Attendance-App](https://github.com/tanmayk1234/Kumbhathon-Intern-Attendance-App)** | Attendance app for Kumbhathon interns. | Next.js, TypeScript |
| **[Admin-Dashboard-Kumbhathon](https://github.com/tanmayk1234/Admin-Dashboard-Kumbhathon)** | The admin side of that attendance system. | Next.js, TypeScript |
| **[agri-feild-web-](https://github.com/tanmayk1234/agri-feild-web-)** | Site for Agri Founders Field, an on-farm venture building program by Sahyadri Farms, DISQ and MSIS. | HTML, CSS, JavaScript |
| **[BASF-KId-Z-LAB](https://github.com/tanmayk1234/BASF-KId-Z-LAB)** | Schedule and data portal for the Kapse Foundation × BASF Kids' Lab program. | Node, Vercel, Excel import |
